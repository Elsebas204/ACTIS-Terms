ACTIS — Condiciones de Servicio

Estas Condiciones de Servicio regulan el acceso y uso de ACTIS ("ACTIS", "el Bot", "la Aplicación" o "el Servicio"), una aplicación desarrollada para la plataforma Discord.

Última actualización: 4 de octubre de 2026

Descripción del Servicio

ACTIS es una herramienta diseñada para proporcionar funcionalidades de asistencia, control, seguimiento e información dentro de servidores de Discord.

Las funciones de ACTIS pueden incluir, entre otras:

  • Herramientas de asistencia para usuarios y equipos.
  • Sistemas de verificación.
  • Gestión y consulta de información.
  • Automatización de determinadas tareas.
  • Funciones relacionadas con la organización y administración de comunidades.

Las funciones disponibles pueden cambiar, actualizarse, suspenderse o retirarse en cualquier momento.

Requisitos de uso

Para utilizar ACTIS debes:

  • Tener una cuenta de Discord válida.
  • Cumplir las Condiciones del Servicio y las Directrices de la Comunidad de Discord.
  • Tener los permisos necesarios para utilizar las funciones de ACTIS dentro del servidor correspondiente.
  • No utilizar ACTIS para actividades ilegales, abusivas, fraudulentas o maliciosas.

El uso de ACTIS está sujeto también a las políticas y requisitos establecidos por Discord.

Uso aceptable

Al utilizar ACTIS, aceptas no utilizar el Servicio para:

  • Realizar actividades ilegales o fraudulentas.
  • Intentar obtener acceso no autorizado a cuentas, servidores o sistemas.
  • Interferir deliberadamente con el funcionamiento de ACTIS o Discord.
  • Intentar explotar vulnerabilidades del Bot.
  • Utilizar las funciones del Bot para acosar, amenazar o perjudicar a otras personas.
  • Distribuir contenido malicioso mediante ACTIS.
  • Intentar evadir sistemas de seguridad, permisos o restricciones.
  • Utilizar ACTIS de una manera que infrinja las políticas de Discord.

Nos reservamos el derecho de restringir o impedir el acceso a ACTIS cuando consideremos que existe un uso abusivo o contrario a estas Condiciones.

Verificaciones

Algunas funciones de ACTIS pueden requerir procesos de verificación.

Las verificaciones pueden utilizar información proporcionada voluntariamente por el usuario o información necesaria para completar el proceso correspondiente.

ACTIS no garantiza que una verificación sea infalible. Los administradores del servidor son responsables de establecer y supervisar sus propios requisitos de acceso y verificación.

Información y datos

ACTIS puede procesar determinada información necesaria para proporcionar sus funciones.

La información procesada dependerá de las funciones utilizadas y de la configuración del servidor.

ACTIS no solicita deliberadamente información que no sea necesaria para proporcionar sus funciones. Los usuarios y administradores deben evitar proporcionar información personal innecesaria a través del Servicio.

El tratamiento de datos puede estar sujeto a una Política de Privacidad independiente.

Disponibilidad del Servicio

ACTIS se proporciona según su disponibilidad.

No garantizamos que el Servicio esté disponible de forma permanente, ininterrumpida o libre de errores.

El Servicio puede experimentar interrupciones debido a:

  • Mantenimiento.
  • Actualizaciones.
  • Problemas técnicos.
  • Fallos de terceros.
  • Problemas relacionados con Discord.
  • Circunstancias fuera de nuestro control.

Podemos modificar, suspender o retirar cualquier función de ACTIS en cualquier momento.

Integración con Discord

ACTIS funciona mediante la plataforma y los servicios proporcionados por Discord.

ACTIS no es propiedad, patrocinio ni representación oficial de Discord, salvo que se indique expresamente lo contrario.

El uso de ACTIS requiere el cumplimiento de las políticas y condiciones aplicables de Discord.

Propiedad intelectual

ACTIS, incluyendo su nombre, identidad visual, código, diseño, documentación y elementos originales asociados al Servicio, pertenece a sus respectivos propietarios o licenciantes.

Estas Condiciones no conceden al usuario ningún derecho de propiedad sobre ACTIS.

No está permitido copiar, modificar, redistribuir, vender o utilizar elementos de ACTIS sin la autorización correspondiente, salvo cuando la legislación aplicable permita expresamente hacerlo.

Servicios y contenido de terceros

ACTIS puede depender de servicios, APIs o plataformas de terceros.

No somos responsables de cambios, interrupciones, errores o problemas ocasionados directamente por servicios externos.

El uso de servicios de terceros puede estar sujeto a sus propias condiciones y políticas.

Limitación de responsabilidad

ACTIS se proporciona "tal cual" y según disponibilidad.

En la medida permitida por la legislación aplicable, no garantizamos que el Servicio sea completamente seguro, preciso, ininterrumpido o libre de errores.

No nos hacemos responsables de pérdidas, daños o consecuencias derivadas del uso incorrecto del Servicio, de decisiones tomadas utilizando información proporcionada por ACTIS o de interrupciones ocasionadas por terceros.

Modificaciones de estas Condiciones

Podemos modificar estas Condiciones cuando sea necesario para reflejar cambios en ACTIS, sus funciones, requisitos legales o políticas aplicables.

Cuando se realicen cambios importantes, se actualizará la fecha de "Última actualización" de este documento.

El uso continuado de ACTIS después de la publicación de modificaciones constituye la aceptación de las nuevas Condiciones, en la medida permitida por la legislación aplicable.

Terminación

El acceso a ACTIS puede ser suspendido o terminado si un usuario incumple estas Condiciones, las políticas de Discord o utiliza el Servicio de forma abusiva.

Los administradores de un servidor también pueden retirar ACTIS de su servidor en cualquier momento.

Contacto

Si tienes preguntas relacionadas con estas Condiciones, ACTIS o sus funciones, puedes contactar con el equipo responsable del Servicio mediante los canales oficiales de soporte disponibles.

Aceptación

Al utilizar ACTIS, confirmas que has leído y comprendido estas Condiciones de Servicio y que aceptas cumplirlas.
